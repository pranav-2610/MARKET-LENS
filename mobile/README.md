# Mobile app

Before first run:
1. Install a supported Node.js LTS.
2. Run `npm install`.
3. Replace `API_BASE_URL` in `src/config.ts`.
4. Ensure the API is reachable from the phone.
5. Run `npx expo start`.

If Expo dependency versions have changed since this starter was created, use `npx expo install --fix` and resolve version warnings before building.
